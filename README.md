# Aarushi Bajaj Portfolio (static site)

Plain HTML, CSS and JavaScript. No npm, no build.

- Edit text: open `index.html`, find `const D=` near the bottom and change the values (name, email, `linkedin`, case studies).
- Photos: `images/` (keep the file names). Resume: `Aarushi_Bajaj_Resume.pdf`.
- Deploy: push this folder to GitHub, import it in Vercel, Framework Preset **Other**, leave Build Command and Output Directory empty.
